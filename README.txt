FitFuel PWA v4

New in v4:
- Personal recipe database
- Add custom recipes with macros, ingredients and directions
- Automatic 7-day meal-plan generation from the recipe database
- Regenerate a new weekly meal plan
- Edit each day's meal list and add/remove recipes
- Automatically generated weekly grocery list from selected recipe ingredients
- Grocery checklist
- Existing workout, water, progress, backup and iPhone PWA features

Host the folder at an HTTPS URL. On iPhone Safari use Share -> Add to Home Screen -> Open as Web App -> Add.
